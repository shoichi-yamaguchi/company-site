# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」のコーポレートサイトです。`index.html` 1ファイルだけで動く1ページ構成のサイトで、ビルドやサーバーは必要ありません。

> 社名・人名・住所・電話番号・実績などはすべて架空のものです。

## サイトの概要

「夕暮れの街」と「ビルの断面図」をテーマにデザインしています。ページは上から次のセクションで構成されています。

| セクション | 内容 |
| --- | --- |
| お知らせ | 日付・カテゴリ付きの最新情報 |
| ヒーロー | キャッチコピーと、窓の灯りが点滅する夜景のアニメーション |
| サービス | 事業内容を B1〜5F のビルの階に見立てて紹介 |
| 開発実績 | 3件の事例と成果の数値 |
| 進め方 | 現地調査 → 設計 → 施工 → 運用・改修 の4ステップ |
| 会社概要 | 会社情報の表と代表メッセージ |
| お問い合わせ | 入力チェック付きのフォーム（デモのため実際には送信されません） |

### 主な仕様

- HTML・CSS・JavaScript をすべて `index.html` に記述
- フォントは Google Fonts（Big Shoulders Display、Zen Kaku Gothic New、JetBrains Mono）から読み込み
- ライトモード／ダークモードは OS の設定に合わせて自動で切り替わる
- スマートフォン幅にも対応
- OS の「視差効果を減らす」設定がオンのときは、夜景のアニメーションを止める

## ブラウザで index.html を開く手順

### 方法1：ファイルを直接開く

1. Finder（Windows ではエクスプローラー）でこのフォルダを開きます。
2. `index.html` をダブルクリックします。既定のブラウザでページが開きます。
   - 別のブラウザで開きたい場合は、`index.html` をそのブラウザのウィンドウにドラッグ＆ドロップします。

ターミナルから開く場合は、このフォルダで次のコマンドを実行します。

```sh
# macOS
open index.html

# Windows（PowerShell）
start index.html

# Linux
xdg-open index.html
```

### 方法2：ローカルサーバーで開く

ファイルを直接開いても表示できますが、本番に近い環境で確認したい場合はローカルサーバーを使います。Python が入っていれば、このフォルダで次のコマンドを実行します。

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開くと、サイトが表示されます。終了するには、ターミナルで `Ctrl + C` を押します。

### 補足

- Web フォントの読み込みにはインターネット接続が必要です。オフラインでもページは表示されますが、フォントは端末に入っている代替フォントになります。
- 内容を編集したら、ブラウザを再読み込みすると反映されます。
